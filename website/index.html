adscli is a desktop command-line application named adscli. Sign in with your Google account, then list and change campaigns, asset groups, assets, and reports from a terminal or a k9s-style TUI.

What adscli does Install Source

Purpose of adscli

The application name is adscli. adscli is an open-source desktop program you install on your computer. It is not a website you log into. This page is the product homepage for adscli.

adscli’s purpose is to let people operate their own Google Ads accounts from a command line or a terminal user interface. After you install adscli and run adscli login, you grant adscli permission to call the Google Ads API as you. You can then:

  • list the Google Ads accounts your Google user can already open
  • browse, create, update, enable, or pause campaigns
  • manage Performance Max asset groups and assets
  • pull performance reports and run GAQL queries

adscli requests the Google Ads scope (https://www.googleapis.com/auth/adwords) so those commands can run. It does not request Gmail, Drive, Calendar, or other Google data. API calls go from your copy of adscli to Google. adscli does not operate a backend that stores your Ads data. See the adscli privacy policy.

adscli is built for humans and for software agents. Every command documents itself with adscli --help and adscli schema --json.

Built for agents. Fine for humans.

Self-describing

adscli --help and adscli schema --json are the docs. No extra manual required.

Structured I/O

Global --json. Errors on stderr. Exit codes 0–5. Mutations need --yes.

k9s-style TUI

Drill campaigns → asset groups → assets. Filter, enable, pause. Bare adscli needs a TTY.

Browser SSO

adscli login is Desktop OAuth + PKCE. Every build ships the branded adscli client.

Install

Homebrew (macOS and Linux)

brew install dvaldivia/tap/adscli

From a GitHub Release tarball

VERSION=0.0.4 OS=linux ARCH=x86_64
curl -sSL -o adscli.tar.gz \
  "https://github.com/dvaldivia/adscli/releases/download/v${VERSION}/adscli_${OS}_${ARCH}.tar.gz"
tar -xzf adscli.tar.gz
install -m 0755 adscli /usr/local/bin/adscli

From source

cargo install --git https://github.com/dvaldivia/adscli adscli

Try it

adscli version --json
adscli schema --json
adscli login
adscli customers list --json
adscli campaigns list --json --limit 20

Auth

Official adscli release binaries may ship a shared Desktop OAuth client. adscli login uses it unless you set ADSCLI_CLIENT_ID / ADSCLI_CLIENT_SECRET (or the same keys in a config file). You still click Allow as yourself. Source builds do not include those values.

The Google Ads developer token is not shipped. Set ADSCLI_DEVELOPER_TOKEN before API calls. Check adscli auth status --json for has_oauth_client, oauth_from_bundle, and has_developer_token.

Full behavior: adscli login --help and the README.
