Privacy Policy

Effective 18 August 2026. This is the privacy policy for the adscli desktop application, the adscli OAuth client, and this website (adscli.dev).

adscli is an open-source command-line tool and terminal UI for the Google Ads API. It runs on your computer. Source is at github.com/dvaldivia/adscli.

What adscli accesses

When you run adscli login, Google asks you to grant a single scope:

https://www.googleapis.com/auth/adwords

That scope lets adscli call the Google Ads API as the Google user who clicked Allow. adscli can then list and change campaigns, asset groups, assets, reports, and related Google Ads resources in accounts that user can already open in Google Ads.

adscli does not request Gmail, Drive, Calendar, Contacts, Photos, YouTube, Cloud Platform, or any other Google scope. It does not read your Google password. It receives OAuth tokens from Google after you consent.

How adscli uses Google user data

adscli uses Google Ads data only to provide the features you invoke:

  • show accounts, campaigns, asset groups, assets, and reports in the CLI or TUI
  • create, update, enable, or pause those resources when you run a command that says so (mutations require --yes)
  • refresh an access token so later commands keep working

adscli does not use Google user data to serve ads, build profiles, determine creditworthiness, or train machine-learning or generative-AI models. Official binaries do not phone home. API traffic goes from your machine to googleads.googleapis.com and Google’s OAuth endpoints only.

How adscli stores Google user data

After login, adscli stores a refresh token (and related OAuth metadata) on the same machine:

  • in the operating-system keychain when one is available, or
  • in ~/.config/adscli/credentials.json with file mode 0600

Optional local config (~/.config/adscli/config.yaml or .adscli.yaml) may hold a client id, client secret, developer token, and customer ids you set yourself. Campaign, asset, and report payloads are printed to your terminal or written to files you choose; adscli does not keep a remote copy.

This website is static HTML. It does not set cookies, run analytics, open accounts, or receive Google Ads data.

How adscli shares Google user data

We do not sell Google user data. We do not operate a backend that receives your Google Ads data or OAuth tokens. We do not transfer that data to advertisers, data brokers, or AI training services.

The only third party that sees Google Ads data through adscli is Google, because adscli calls Google’s APIs with the token you granted. If you publish logs, screenshots, or exported JSON yourself, that is outside this app.

Limited Use

adscli’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular:

  • Google user data is used only to provide or improve user-facing features of adscli
  • it is not transferred to others except as needed to call Google’s own APIs, to comply with applicable law, or with your direction
  • it is not used for serving advertisements
  • humans do not read your Google user data unless you send it to us (for example in a GitHub issue), you give affirmative consent for a specific request, or we must do so for security or legal reasons — and even then we cannot reach tokens stored only on your machine

Revoking access and deleting data

To stop adscli from using your Google account:

  1. Run adscli logout to delete the local refresh token.
  2. Revoke the app at Google Account permissions.
  3. Delete ~/.config/adscli/ if you also want local config gone.

Because tokens and Ads data stay on your computer, there is no remote account for us to wipe. After logout and revoke, adscli cannot call the API as you until you sign in again.

This website

adscli.dev serves this policy, a homepage, and support. It does not collect personal information. Server access logs, if any, are those of the host and are not used to identify visitors of this site.

Children

adscli is not directed at children under 13 (or the equivalent age in your jurisdiction). We do not knowingly collect their data.

Changes

If this policy changes, we will update this page and the effective date above. Continued use of adscli after a change means you accept the updated policy.

Contact

Questions about this policy or adscli’s use of Google user data: github.com/dvaldivia/adscli/issues or support.
